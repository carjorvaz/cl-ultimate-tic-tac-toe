# Plans

Last reviewed: 2026-05-30

Most changes are small enough for an ephemeral checklist. Create a checked-in
execution plan for multi-step work with durable uncertainty.

## When To Create A Plan

Create a plan for cross-layer behavior, substantial UI changes, reliability
work, or refactors where the target architecture matters.

## Plan Location

- Active plans: `docs/exec-plans/active/`.
- Completed plans: `docs/exec-plans/completed/`.
- Small cleanup candidates: `docs/technical-debt.md`.
